# Contribución

## Flujo de trabajo

- `main`: versión estable y demostrable.
- `develop`: integración del trabajo del equipo.
- ramas `feature/<nombre>`: cambios por funcionalidad.

Todo cambio relevante debe llegar a `main` mediante Pull Request. No se deben versionar credenciales, datasets originales ni artefactos pesados de modelos.

## Convención de commits

Se recomienda Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`.
